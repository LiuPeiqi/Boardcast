# Boardcast for macOS

这是独立 Swift / SwiftUI 实现，不引用 Windows 源码或 .NET。最低 macOS 13，使用系统 Network.framework、Security、CryptoKit、ServiceManagement，无第三方 Swift 包或需用户安装的运行时。

**验证状态：源码已落地，本次 Windows 工作环境没有 Swift/macOS SDK；尚未在 Mac 编译、运行或与 Windows 互通。不能把此目录视为已经验证的可分发成品。** GitHub Actions 已配置 macOS 构建与规则测试，只有 CI 和真实双机验收通过后才应发布。

后续开发采用 [macOS 产品与界面设计](../../docs/macos-design.md) 和 [本地开发交接](DEVELOPMENT.md)。方案覆盖最新 Windows 操作精简、原生工作台、菜单栏与 Finder、接收存储及能力迁移；方案中的新增行为尚未实现，现有源码能力以下文为准。

## 已编写的功能

- SwiftUI 设备列表、发送文件/文件夹、接收确认、菜单栏常驻、登录启动、备注/信任设置。
- 设备分组：名称前缀自动匹配、本机自定义分组、个人设备分组覆盖；附近列表支持全部、同组或多组选，并保存选择。发现与 hello 兼容旧设备缺少分组字段。
- 独立规则实现：first-match、设备信任与自动接收双授权、所有文件后缀匹配、顶层文件夹通配符、默认/规则接收路径。
- 当前物理接口 IPv4 子网广播发现；每 60 秒一次，系统调度允许 5 秒合并；不扫描网段。
- Network.framework TLS 双向证书身份；P-256 私钥保存在 Keychain；证书 DER SHA-256 指纹。
- 4 MiB 有界 JSON 帧，1 MiB 数据缓冲，最多两个连接；按清单流式传输并校验每文件 SHA-256。
- 收到的批次在临时目录完成全部校验，再移动成独立批次目录；不覆盖已存在文件。
- 路径穿越、符号链接、特殊文件、大小溢出、Windows 保留名、NFC/大小写冲突检查。

只接受当前接口子网的数值 IPv4 直连地址，排除 utun/ppp；没有公网域名解析、云中继、穿透、互联网自动降级。IPv6 和跨 VLAN 路由尚未支持。

## 分组使用

- 默认按设备原名称的首个非空前缀分组，分隔符为连字符、下划线、点或空白，例如 Design-Mac 与 Design-PC 同组；备注不会改变自动分组。没有分隔符时使用完整名称。
- 在通用设置填写“我的分组”并保存，向附近设备公开该分组；留空恢复名称前缀匹配。
- 在“备注、分组与信任”填写“个人分组”，仅覆盖自己看到的该设备分组。优先级为个人分组、对方公开分组、原设备名称前缀。
- 附近设备选择“选择分组”后可勾选多个分组；留空选择时显示零台设备。筛选会保存，下次启动继续使用。
- 如需默认只显示同组设备，在通用设置将“附近设备默认显示”改为“与我同组”并保存；也可以直接在附近列表选择该选项。随时切换“全部设备”恢复完整列表。
- 组名忽略首尾空白和大小写，自定义组名最多 80 个 UTF-16 代码单元，不接受控制字符；最多选择 128 个分组，自动前缀作为筛选项最多 256 个 UTF-16 代码单元。空设备名或纯分隔符归入“未分组”。分组只影响列表展示，不改变后台发现、传输、信任或自动接收规则。

## 在 Mac 构建

安装 Xcode 命令行开发工具后：

```sh
cd platforms/macos
swift test
bash scripts/build.sh
open dist/Boardcast.app
```

生成 Apple Silicon + Intel 通用 app 和 ZIP。默认采用本地 ad-hoc 签名；向其他人正常分发前，需要设置 `SIGN_IDENTITY` 为自己的 Developer ID，进行公证，并在一台干净 Mac 验证 Gatekeeper。脚本不会自动申请证书、上传公证或发布。

## 双机发布前验收

1. Windows 与 Mac 同一网段能发现，端口 TCP/UDP 45831，暂停状态可见。
2. 两端手动发送单文件、空文件、空目录、多级目录，逐文件比较 SHA-256。
3. 指纹不一致拒绝；只有手动核对并开启设备授权与匹配规则后自动接收。
4. 拒绝、120 秒未确认或提交前断开时无正式完成目录；提交后回执失败保留已保存目录并准确记录状态，同名批次不会覆盖。
5. 未经用户操作不运行 CLI、不上传摘要。此 macOS 实现还没有 CLI/MCP/LLM 集成。
6. 测量菜单栏空闲 30 分钟 CPU、RSS、唤醒次数；对比大文件与十万小文件的速度/耗时，调整协议限额后才能测十万项。
7. 首次本地网络权限、Keychain 权限、重启后身份持久化、注销/登录项行为，以及 Intel/Apple Silicon 分别验证。
8. 新旧 Windows/Mac 互相发现和握手，公开组名同步、个人覆盖不外传、多组选与同组筛选重启后保留；被隐藏的可信设备仍按原规则接收。

当前 macOS 的常驻形态是登录用户的菜单栏应用，不是在用户退出后运行的系统 daemon；关闭窗口继续等待文件。
