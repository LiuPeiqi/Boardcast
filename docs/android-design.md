# Boardcast Android 手机和平板设计

Boardcast 在 Android 上继续完成同一局域网内的文件与文件夹发送、接收和可靠保存。手机以单手可达的分步发送为主，平板在空间充足时并列显示内容与设备；两者共用发送草稿和任务语义。文件类型、目录层级、身份核对与完成回执沿用现有产品，导航、触控、系统选文件与后台行为采用 Android 的习惯。

本方案以 2026 年 10 月 10 日的 Windows 0.2.7、[Mac 设计](macos-design.md)、[图标规范](file-icons.md)和[协议](protocol.md)为基线。Android 当前为设计阶段：本次交付界面设计与目录存储规范，没有创建 Android 源码、Gradle 工程或安装包。预览中出现的按钮不表示能力已完成。完整目录与权限约束见 [Android 文件和目录存储设计](android-storage-design.md)。

## 产品范围

保留一次性发送文件和文件夹、混合草稿、附近设备、多目标、来件确认、任务历史和设备信任。首版不扩展为全盘文件管理器、云盘、持续同步或清理工具。系统文件选择器承担寻找源内容，Boardcast 内的目录清单用于核对选中内容、排除子项与检查收到的结构。

局域网直连不要求互联网可用，不加入账号、公网中继或互联网自动降级。发现遵循现有 IPv4 子网边界；手动地址连接仍受网络与权限约束，不承诺跨 VLAN、唤醒休眠设备或与 AirDrop、LocalSend 互通。会访问云端的系统文件提供方需要单独说明，不能把其网络行为称为局域网传输。

发现与分组用于寻找设备，证书 DER 的 SHA-256 指纹识别身份。信任、设备自动接收和规则自动接收分别授权；接受一次来件只批准本次文件。接收不授权执行文件、安装应用或调用外部服务。

发送保持顶层名称、相对层级与空目录，不预打 ZIP，不自动平铺。统计与传输使用相同排除条件，发送前仍重检。未知大小显示“正在读取信息”，不可读子项列出原因；不能默默漏传后宣告全部完成。

## 手机和平板布局

依据实际窗口可用宽度、高度、字体与折叠姿态决定布局，不按设备名称固定界面。旋转、分屏、展开折叠屏或改变窗口大小时，保留草稿、设备选择、目录位置、搜索、任务与详情。[Android 窗口尺寸类别](https://developer.android.com/develop/adaptive-apps/guides/use-window-size-classes)

| 窗口宽度 | 主导航 | 发送布局 | 任务与详情 |
| --- | --- | --- | --- |
| 小于 600 dp | 底部导航 | 内容页 → 选择设备页 → 发出，每步一个主动作 | 列表进入独立详情 |
| 600 至 839 dp | 高度允许时使用窄导航轨 | 保留分步流程，不把列表挤成两窄栏 | 单主栏，详情替换列表 |
| 840 至 1199 dp | 导航轨 | 文件和附近设备双栏，可用内容约 56:44 | 列表与详情双栏 |
| 1200 至 1599 dp | 可展开导航轨 | 给名称与清单更多空间 | 加宽详情，限制正文阅读宽度 |
| 1600 dp 及以上 | 同一导航体系 | 保持双栏和合理最大行宽 | 不放大图标填充空白 |

840 dp 是进入双栏的候选条件；扣除导航轨、内边距、铰链和字体扩展后，两栏仍不足时退回分步。高度小于 480 dp 的横屏减少大标题和重复工具层。铰链不承载按钮、文件名或进度，需要时将相关栏放在两侧。旋转不取消任务。

三个同级入口为“发送”“传输”“设置”。手机顶级页面使用 NavigationBar，子页使用顶部返回并隐藏顶级底栏，保留本页主操作。平板导航轨保留相同入口。“传输”徽标只表示待确认来件数量，不把历史任务数当未读数。[Android 导航模式](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns)

## Android 视觉与操作

采用 Material 3 的语义色、系统字体、顶部应用栏、导航栏或导航轨、选择控件、菜单、底部抽屉和对话框。Android 12 及以上允许系统动态配色，其他系统和用户关闭动态色时使用品牌回退色。浅深外观与主题变化不改变状态含义。[Android 色彩](https://developer.android.com/design/ui/mobile/guides/styles/color)、[Material 3](https://developer.android.com/develop/ui/compose/designsystems/material3)

列表承担信息，留白保持层级，避免多重卡片、重复阴影与大品牌标题占用内容区。以下为设计起点，最终按系统组件和真实字体校准。

| 对象 | 设计起点 | 必须满足 |
| --- | --- | --- |
| 页面内边距 | 手机约 16 dp，平板约 24 dp，相关控件间 8 至 12 dp | 窄窗口与系统栏下不遮挡动作 |
| 字体 | 正文约 16 sp，次级约 14 sp，标题采用系统语义字号 | 随系统缩放，不靠缩小字体维持单行 |
| 动作图标 | 常规约 24 dp | 点击范围至少 48×48 dp，相邻范围不重叠 |
| 文件行 | 约 64 至 80 dp，随内容增长 | 名称和统计必要两级，完整信息可查看 |
| 设备行 | 常规约 64 dp | 一行优先，大字允许增高或换行 |
| 主要按钮 | 系统 FilledButton，约 48 dp 或更高 | 手机靠下，横屏和键盘展开时仍可达 |
| 错误与状态 | 图标、文字和针对性操作 | 不以颜色或短暂提示独立表达 |

点按查看内容或执行明确操作，长按进入上下文选择。文件多选模式显示选择数量、取消选择和移除；更多菜单提供等价入口。移除和清空只改发送草稿，不删除源文件。平板拖放是补充，添加、排除与排序都有触控和键盘替代。[Android 无障碍](https://developer.android.com/design/ui/mobile/guides/foundations/accessibility)

背景可延伸至系统栏后，关键按钮、底栏、抽屉操作和输入框避开状态栏、切口、导航栏与手势区。返回依当前界面先关闭键盘或临时层、退出选择，再回详情或上一页，最后由系统离开应用；不使用“双击返回退出”，不把返回当取消传输。[边到边布局](https://developer.android.com/develop/ui/views/layout/edge-to-edge)、[预测性返回](https://developer.android.com/design/ui/mobile/guides/patterns/predictive-back)

## 文件和平台图标

文件类型沿用现有 [36 张设计资产与分类](assets/icons/catalog.json)：32 个原类型、Mac 文件夹代表与三个平台标记。它们尚不是 Android 运行资源。文件保留原几何、原色和比例，不用通用线框文件图替代；目录优先、特殊文件名优先、最后扩展名、忽略大小写和未知中性文件规则继续一致。分类不访问远端路径。

普通文件夹采用 Android Material 的 filled folder 轮廓与主题色，作为已允许的平台外观例外。Android 没有与 NSWorkspace 相同的任意桌面路径图标查询约定；不把 Mac 蓝色代表或某个厂商文件管理器的图标称为所有 Android 的系统图标。空目录用计数和结构表达，不另造颜色语义。

Windows 四格、Mac 笔记本与未知平台显示器保留现有几何。Android 新增手机与平板的设计标记，视觉重量需与现有平台图协调；只在对端明确提供形态时区分手机和平板，缺少字段时使用中性 Android 设备标记，不能根据名称猜测。该扩展需后续补资产和兼容映射，本次不改 catalog 的36项定义。

动作采用统一 Material Symbols 或原生图形，平台标记使用 onSurfaceVariant 单色，文件类型保留彩色资产。预览通用动作符号仅作布局示意。缩略图需用户授权、提供方支持和真实需求，默认不为生成缩略图读取全部内容。

## 发送流程

### 手机内容页

标题“发送”，本机名称与可展开局域网状态保持可查看。文件区“待发送”显示顶层项数；文件数、文件夹数和总大小另行表达，不把顶层项数写成文件数。

空草稿只有“添加文件或文件夹”与主要添加入口。点击后以底部菜单选择“文件”或“文件夹”：前者进入系统多选文件面板，后者进入系统目录树选择器，选完合并到同一草稿。不能照搬 Mac 同一面板任意混选文件和目录。[系统文件和目录选择](https://developer.android.com/training/data-storage/shared/documents-files)

非空标题区保留添加与更多菜单。更多含选择、清空、发送说明；移除、排除和完整清单在存在相关对象时出现。扫描显示“正在统计”“部分内容无法读取”或完整结果，错误留在对应项并有详情和重新授权入口。

完整名称与完整统计在扣除图标、触控动作和间距后的区域能自然放下时采用一行，名称在前、统计靠后；否则名称与统计分两行。不能先省略名称再判定能放下一行。手机通常两行，平板短名称可一行；宽度、字体、语言、扫描与排除变化后重新判断，完整信息通过详情可查看。

点按目录进入所选内容的结构清单，通过面包屑、上级返回与文件夹行保持层级，不扩大授权。排除使用明确相对路径，目录排除覆盖子树。多个同名来源有来源标签，不能因显示名相同合并；父目录与其子项的重复选择应提示去重。

底部显示摘要与“选择设备”。无内容或存在阻断错误时解释禁用原因；完整空目录可发送，不能因 0 B 禁用。发送说明默认折叠，展开为多行输入，不自动生成摘要。

### 手机选择设备页

顶部返回待发送，保留内容。附近设备工具区允许标题操作行和筛选行分开，不能将长组名、数量、刷新、搜索强塞进桌面式单行。下拉刷新为补充，保留显式刷新，状态变化不移动按钮。

常规设备行呈现选择控件、平台图标、备注或原名、必要状态和真实运行版本。正常设备不重复标“在线”；暂停、离开或无法连接有具体原因。未知版本省略，灰色运行版本不表示最新。首版不开放蓝色更新按钮，Windows 0.2.7 不构成 Android 更新资格。

行主体选择目标，右侧独立可聚焦详情按钮查看信息；触控区域互不覆盖，详情不改变勾选。受限设备仍可核查详情，但不可发送。大字优先保留名称与状态，将版本移入详情，允许行高增长。

文字搜索保留选择；隐藏目标显示“另有 N 台已选设备”并可查看。分组筛选清除被隐藏目标并反馈，沿用现有语义。最终发送前展示全部目标，不只列当前搜索结果。

底部为已选数量与“发送到 N 台设备”。未知设备可作为目标，首次身份与接收批准由传输流程处理。发出后每设备建立独立任务，手机进入传输页；保留可编辑草稿副本，编辑不改变已提交任务快照。

### 平板双栏发送

导航轨旁并列待发送与附近设备。添加与清空属于文件区，分组、计数、刷新与搜索属于设备区；空间充足时设备工具栏保持一行信息层级，长组名进菜单，不额外堆一行分组标签。

两个列表各吸收可用高度，说明与次级动作按需出现，核心操作显隐不造成外框跳动。底部全局摘要同时表示内容与目标，只有一个发送动作。目录或设备详情替换相关栏，较窄时打开完整子页，不叠第三窄栏。

## 来件确认

主页面出现轻量来件提示，传输入口显示待确认数。点击提示或通知打开对应请求；通知提醒，真实授权在详情完成。锁屏通知默认不展示完整文件名、说明和指纹。

详情依次显示发送者备注与原名、身份状态、数量与大小、发送说明、完整目录清单、保存位置与批准期限。说明是普通文本，不自动打开链接。手机使用完整页面，平板使用任务详情栏；接受与拒绝持续可达。

完整目录首次接收前选择可写系统目录树，建议 Documents/Boardcast 或合法 Download/Boardcast 子目录。未授权显示“选择接收文件夹”，不捏造默认物理路径。已有授权用“提供方 › 卷 › 目录”表达实际位置，“更改”进入系统目录选择。预览的“内部存储 › Documents › Boardcast”是已授权示例。

“接收”只批准当前批次，信任和自动接收另有独立设置。已信任设备也展示实际目录和规则原因。期限取任务真实截止时间；Windows 的五分钟和当前 Mac 的120秒不能写成跨端统一固定值。过期按钮失效，提示请对方重发。

批准后、写入前重检身份、接收开关、规则、目录能力、权限与容量。不能保留目录时说明差异并更换位置，不自动平铺。期限内无法解决则明确过期。逐文件提交、冲突与取消见配套存储设计。

## 传输记录和完成行为

传输页分进行中、待确认和历史，必要时筛选全部、发送与接收。手机进入独立详情，平板列表加详情；用户查看历史时，新广播不反复抢走焦点。

阶段分别为排队、准备、等待确认、传输、校验、保存、完成、部分已保存、拒绝、取消、中断与回执未确认。字节传到100%后仍明确“正在校验”或“正在保存”；发送端收到有效完成回执后才表示对方已保存。

多目标父任务显示完成与失败数量，每设备保留独立批准、进度和错误。一个目标失败不停止其他；取消全部需表达范围。速度和预计时间只在有足够样本时出现，网络切换和温控中断不沿用无根据速率。

暂停和继续仅在真实块协商及持久恢复完成后出现；legacy中断提供“重新发送”。取消保留已保存文件，详情显示数量和真实位置；不承诺撤回对方已经保存的内容。

完成后提供真实可用的打开文件、保存位置与分享。打开交系统解析器，分享用系统 Sharesheet 与受控URI授权。提供方不支持打开目录时，显示文件清单和位置说明，不能摆放无效入口。删除历史记录只删记录，删除实际文件是独立明确动作。[Android 分享](https://developer.android.com/develop/ui/compose/sharing/send)

错误持久保留，有重新选源、重新授权、清理空间或重试等针对性操作。Snackbar只承担短反馈。从其他应用分享来的临时URI不是永久源，进程重建或重试可能需要重新选择。[接收系统分享](https://developer.android.com/develop/ui/compose/sharing/receive)

## 网络权限和后台生命周期

目录、附近设备与通知分别解释，按实际操作触发。首版不依赖所有文件访问、蓝牙、定位或电池优化白名单作为泛化前置；采用API的真实需求才能增加权限。手输IP或扫码不能绕过局域网授权。[局域网权限](https://developer.android.com/privacy-and-security/local-network-permission)

| 环境 | 设计行为 |
| --- | --- |
| Android 16 常规LAN | 不将普通TCP／UDP一律设计为需要新的运行时附近设备权限 |
| Android 16 主动opt-in限制测试 | 按官方机制验证临时NEARBY_WIFI_DEVICES授权，不当全部用户行为 |
| Android 17，target SDK ≤36 | INTERNET保留隐式LAN授权，不凭系统版本造新弹窗 |
| Android 17，target SDK ≥37 | 直接发现与连接需ACCESS_LOCAL_NETWORK运行时授权，属于附近设备组 |
| Android 13及以上通知 | 在首个持续传输提醒时解释与申请；拒绝仍保留应用内操作 |

设备数为零不能直接判权限拒绝；区分无有效LAN、已知授权拒绝、扫描中、无设备与扫描异常。无互联网Wi-Fi仍可有LAN。以太网、热点、隔离网络分别验收，网络切换后更新接口和状态，不无限重试旧IP。

默认仅在前台提供新来件发现和接收入口。“接收新请求”注明“应用在前台时”；返回桌面不等于人工取消已批准任务，也不保证离开界面后永久可发现。没有活动任务时停止高频扫描和更新，不迁移桌面托盘、菜单栏或开机daemon。

用户主动发出或批准的持续传输可评估 Android 14及以上用户发起数据传输任务，按要求提供通知与取消。其他版本和不适用场景评估正确前台服务机制；长时监听不能伪装成有限传输。系统仍可能因温控、内存或用户停止而结束任务，持久状态表达真实结果。[用户发起传输任务](https://developer.android.com/develop/background-work/background-tasks/uidt)

运行在Android 15及以上且target SDK至少35的应用，dataSync前台服务受后台累计每24小时六小时限制；同类服务共享额度，用户回到前台会重置计时。这不是所有传输API的统一六小时限制，该目标版本也不能从开机广播启动dataSync。通知拒绝不等于禁止前台服务，但提示可能只见系统任务管理器，不能保证通知栏可见。[前台服务超时](https://developer.android.com/develop/background-work/services/fgs/timeout)、[通知权限](https://developer.android.com/develop/ui/compose/notifications/notification-permission)

未来后台等待接收须单独验证合法机制、时限与停止操作，通过实机与发行要求验收后才开放开关。当前不保证无限常驻、锁屏必达或自动重启。

## 设置和设备详情

设置为通用、接收与保存、设备与信任、规则和关于。手机列表进入子页，平板可列表加详情，不用多个桌面弹窗。设备名、公开分组、语言外观、接收目录、缓存与本机身份各有清楚入口。首版简中英文，数量、容量与时间系统本地化。

设备详情显示完整备注、原名、平台、实际版本、地址、分组、最后发现、接收状态和完整可复制指纹。备注不改变身份与分组来源，证书变化形成新身份，名字和IP不能继承信任。

身份信任和允许规则自动接收是两项设置。自动接收需要设备和规则双授权、系统允许接收与有效可写目录；信任不免除系统文件权限。first-match规则可显式上移下移，拖动仅补充；预览显示命中原因与真实位置，不授予许可。

接收暂停只影响新请求，不取消已批准任务；下线与暂停接收使用不同文案。即时偏好、设置草稿与已保存配置分离，保存失败保留输入，开关不得领先服务真实状态。

关于页展示Android自己的版本、协议与许可证。首版只有灰色对端运行版本；更新需另行验证平台包、渠道、发行签名与系统安装确认，不照搬Windows替换重启。收到APK只是普通文件，不自动安装。

## 可访问性和典型状态

TalkBack读出名称、类型、结构、选择与受限原因；选择和详情分别聚焦。数量变化克制播报，不每个网络事件打断读屏。键盘、鼠标与Switch Access能完成添加、勾选、批准和返回；图标按钮有名称，颜色不独立表达错误或信任。

检查大字、显示缩放、200%字体、长中文英文名称、RTL与减少动画。正文增长，深目录缩进设上限，改用进入下一级和面包屑；完整名称、路径与指纹可查看或复制。

| 状态 | 可见信息与下一步 |
| --- | --- |
| 空草稿 | 添加入口，不出现空的次级工具行 |
| 搜索无结果 | 清除筛选恢复清单，不误开系统选文件 |
| 空设备列表 | 真实网络与权限诊断、刷新和手动连接 |
| 未完成扫描 | 正在统计，区分空目录和未知大小 |
| 源失效 | 标出受影响项，重选或明确排除 |
| 目录未选或失效 | 选择或重新授权，更新真实位置后重检 |
| 容量或写入失败 | 保留任务、更换位置；不改已保存文件 |
| 部分已保存 | 数量与位置，取消只清任务自有未完成内容 |
| 过期或回执未确认 | 批准失效／如实显示已知结果和重试条件 |
| 系统停止任务 | 中断与保留内容，按真实能力继续或重发 |
